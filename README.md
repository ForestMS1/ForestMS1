## 👋 About Me

상용 엔진에서 사용하던 기능을 C++과 DirectX로 직접 구현하며  
렌더링 파이프라인, 애니메이션 시스템, 게임 오브젝트의 생명주기를 공부했습니다.

개인 프로젝트에서는 렌더링·애니메이션·에디터를 만들었고,  
팀 프로젝트에서는 맵 시스템과 렌더링 최적화를 담당했습니다.

기능을 완성하는 데서 멈추지 않고 **데이터 수명주기, 성능, 협업 흐름**까지  
함께 개선할 수 있는 게임 클라이언트 개발자를 지향합니다.

- 🎓 국민대학교 소프트웨어학부 졸업
- 📜 정보처리기사 · SQLD
- 🏆 국민대학교 × 숙명여자대학교 해커톤 장려상
- 🎮 레드브릭 게임잼 완성작 코엑스 전시

## 🔍 What I Focus On

- **Rendering** — 화면에 그려지는 과정과 GPU 작업 구조를 이해합니다.
- **Architecture** — 기능의 추가와 변경을 견딜 수 있는 구조를 고민합니다.
- **Optimization** — 추측보다 프로파일링 결과를 바탕으로 병목을 개선합니다.
- **Tools** — 동료가 콘텐츠를 더 편하게 제작할 수 있는 도구를 만듭니다.
